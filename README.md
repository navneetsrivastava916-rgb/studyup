## 🎯 Features

### 🏠 Home
- Personalized greeting with JEE countdown
- **Days left** to JEE Mains (Jan 20, 2027), Advanced (May 17, 2027), and Diwali syllabus target (Oct 20, 2026)
- Syllabus on-track / behind indicator
- **Daily Lecture Goal** — auto-calculated from 840 total lectures ÷ days left
  - Physics: 306 lectures
  - Chemistry: 225 lectures
  - Mathematics: 309 lectures
- Study Timer with real-time socket updates
- Today's auto-generated tasks with penalty progress bar
- Time analysis (dedicated, needed, daily target for IIT)

### 📊 Progress
- Real success rate ring
- Subject breakdown (Physics / Chemistry / Maths)
- 7-day study hours chart
- IIT chances predictor
- Real streak counter (consecutive study days)
- Real rank from leaderboard
- Achievement system (Consistency, Discipline, Regular, Particular, Time Master, etc.)
- Last year JEE result analysis with weak area identification

### ⚡ Practice
- **Quiz** — Chapter-wise MCQs with PYQ count + explanation
- **Mock Test** — Full timed test (30 Qs, +4/-1 marking), subject-wise scores saved to DB
- **PYQs** — Last 10 years papers by year and shift with high-frequency topic analysis
- **Predictor** — Strong / Medium / Weak chapter classifier

### 📅 Schedule
- Weekly timetable grid
- AI Auto-Schedule Builder (based on wake time, sleep time, weak subject)
- Syllabus completion tracker

### 💡 Tips & Roadmap
- Full JEE 2027 roadmap with milestones
- Study strategy tips (time management, revision, barriers)

### 👤 Profile
- Real rank from study leaderboard
- Streak badge
- Leaderboard (top 10 students by study hours)
- Settings

### 🤖 AI Chatbot (StudyBot)
- Context-aware responses (knows your progress, streak, pending tasks)
- Powered by Claude AI (fallback smart responses without API key)
- Knows your daily lecture target
- Study plans, subject doubts, motivation

## 🚀 Setup & Installation

### Prerequisites
- Node.js v16+
- MongoDB (local or Atlas)
- Git

### 1. Clone the repo
```bash
git clone https://github.com/navneetsrivastava916-rgb/studyup.git
cd studyup
```

### 2. Install backend dependencies
```bash
cd Backend
npm install
```

### 3. Configure environment
```bash
cp .env.example .env
```

Edit `.env`:
```env
PORT=5000
MONGO_URI=mongodb+srv://username:password@cluster.mongodb.net/studyup
JWT_SECRET=your_super_secret_key_here
CLAUDE_API_KEY=sk-ant-api03-xxxx   # Optional - AI chat
NODE_ENV=production
```

### 4. Run locally
```bash
node server.js
```

Open browser → `http://localhost:5000`

## 🌍 Deployment

### Frontend → Vercel
```bash
cd Frontend
vercel --prod
```

### Backend → Railway
1. Push to GitHub
2. Go to [railway.app](https://railway.app) → New Project → GitHub Repo
3. Set Root Directory: `Backend`
4. Add environment variables
5. Deploy ✅
